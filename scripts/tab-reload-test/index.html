What to do

Do the steps in order. Before each step, tap its Start button. When the page comes back, look at the Results box.

1. Open the link

Already done when you opened this page. The result for "Link details present on first open" is in the Results box. Choose the two answers under "About this run" above.

2. Switch apps until the phone drops this tab

Tap Start. Then leave the browser: open the camera and take a few photos, open a game or two, scroll Instagram or TikTok for a few minutes, open maps. Come back to this tab. If the page had to load again, the result fills in. If it says "no reload yet", the phone kept the page in memory — go away again, for longer and with heavier apps. Taking a few minutes of video with the camera usually works.

3. Pull to refresh

Tap Start, then drag the page down from the very top until it refreshes. If there is no pull-to-refresh, use the browser's reload button.

4. Close the tab, then reopen it

Tap Start, close this tab, then bring it back from the browser's recently-closed list. Chrome: tab switcher → ⋮ menu → "Recent tabs" (or "Reopen closed tab"). Safari: tab view → press and hold the + button → pick it from the list. If this is an in-app browser with no tabs, tap "Not possible here".

5. Finish

Fill in the two answers under "About this run", tap Finish this run, then screenshot the Results box (or tap Copy and paste the text into a message).
